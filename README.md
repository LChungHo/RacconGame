# RacconGame · 너구리 (Ponpoko Arcade)

ASP.NET Core MVC와 Babylon.js로 만든 1인용 브라우저 게임입니다. 폰포코를 참고한 20개의 고정 스테이지와 자체 도트 그래픽·효과음을 사용합니다. 원작 ROM과 맵 좌표를 복제한 버전은 아닙니다.

## 실행

개발 환경: .NET SDK 10.0.403, Node.js 24.22.0 이상 25 미만.

```powershell
npm ci
npm run build
dotnet run --project RaccoonGame.csproj --no-launch-profile --urls http://localhost:5080
```

브라우저에서 http://localhost:5080 에 접속합니다. 운영 서버에는 Node.js와 외부 CDN이 필요하지 않습니다.

## 조작

- 방향키 좌우: 이동. 상하: 사다리.
- Space: 압정과 틈을 넘는 낮은 점프. 같은 층의 애벌레와 뱀은 점프로 회피할 수 없으며 사다리로 층을 바꾸어 피합니다.
- Enter / 시작: 게임 시작. P: 일시정지와 계속하기.
- 다른 창으로 이동하거나 캐시된 페이지로 돌아오면 멈춘 상태에서 사용자가 재개합니다.
- 이동·사다리·점프 효과음과 스테이지 클리어 멜로디가 재생됩니다. 음소거 상태에서도 플레이할 수 있습니다.

## 20개 스테이지

당근 → 앵두 → 버섯 → 감 → 옥수수 → 파인애플 → 수박 → 가지 → 멜론 → 밤 → 바나나 → 딸기 → 오렌지 → 무 → 사과 → 포도 → 땅콩 → 복숭아 → 완두콩 → 맥주.

상단에는 현재 단계까지의 먹거리 아이콘만 누적 표시합니다. 1단계는 당근, 2단계는 당근과 앵두입니다.

각 판의 필수 먹거리를 모두 모으면 다음 스테이지로 이동합니다. 마지막 20단계 완료 시 승리합니다. 맵의 틈과 사다리 위치는 단계마다 다르고 애벌레의 이동 속도도 증가합니다.

## 점수와 주머니

- 점수는 먹거리 종류가 아니라 **그 판에서 먹은 순서**입니다.
- 1~11번째: 10, 20, 30, 50, 100, 200, 300, 500, 1000, 2000, 3000점.
- 12번째 이후는 마지막 값인 3000점을 유지합니다. 새 스테이지나 재도전에서는 수집 순서가 초기화됩니다.
- 물음표 주머니는 판마다 4개이며 위치와 결과가 고정됩니다. 주머니는 먹거리 순서를 올리지 않고 필수 수집 대상도 아닙니다.
- 점수 주머니는 일반적으로 2개, 3·9단계는 1개, 4·12·13단계는 3개입니다.
- 점수 주머니는 설정된 100/200/500/1000점을 지급합니다. 뱀 주머니는 같은 층에서 느리게 움직이는 뱀을 생성합니다.
- 클리어 보너스는 남은 타이머의 내림값 × 10점입니다.
- TOP SCORE는 이 브라우저에 저장합니다. 저장이 차단되어도 게임은 계속됩니다.

## 시간과 목숨

한 게임의 기회는 3번이며, 하단 너구리 아이콘이 3→2→1→0으로 줄어듭니다. 새 게임을 시작하면 3개로 복원됩니다. 스테이지 타이머는 120부터 시작합니다. 화면에는 숫자 대신 파란 막대로 표시합니다.
타이머가 1에 도달하면 자동으로 낙하하며 목숨을 잃습니다. 적·가시·화면 아래 이탈·64px 초과 낙하도 사망 조건입니다.

재도전하면 현재 스테이지의 시간·먹거리·주머니·적이 초기화되고 점수는 그 스테이지 시작 시점으로 돌아갑니다. 최고 점수는 유지됩니다.

## 검증

```powershell
npm run test:unit
npx playwright install chromium
npm run test:e2e
dotnet build RaccoonGame.csproj -c Release
```

단위 테스트는 20개 고정 맵을 실제 이동 입력으로 각각 클리어하고 전체 게임 진행도 검증합니다.
브라우저 테스트는 대표 맵의 키 입력 진행, HUD·시간 막대·20개 아이콘·최고 점수 복원, 화면 크기, 재시작과 BFCache 수명주기를 확인합니다.

## IIS 배포

```powershell
powershell -NoProfile -File scripts/publish.ps1
```

[배포·복구 안내](docs/deployment/iis.md)를 따릅니다. 게시 검증은 artifacts/publish를 기준 경로로 실행해 /ponpoko/ 아래의 리소스와 실행을 확인합니다. 실제 IIS 서버 배포는 별도 작업입니다.

## 구현 경계

MVC는 페이지·설정을 제공하고, JavaScript는 고정 60Hz 규칙을 계산하며 Babylon.js는 직교 화면을 그립니다. 계정·DB·온라인 순위표·멀티플레이·터치 조작은 포함하지 않습니다.
