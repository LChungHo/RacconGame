# 화면·점프·음향 추가 수정

작성일: 2026-10-30

## 반영 사항

- 상단 먹거리 아이콘은 현재 스테이지까지 누적합니다. 1단계는 당근1개, 2단계는 당근과 앵두2개이며 이후 같은 규칙입니다. 미래 단계는 표시하지 않습니다.
- 게임 속 먹거리의 표시 크기를8×8에서16×16으로, 물음표 주머니 표시 크기를10×12에서18×20으로 확대했습니다. 기존 수집·함정 판정 영역은 유지했습니다.
- 하단에 남은 기회를 너구리 아이콘3개로 표시합니다. 사망하면3→2→1→0으로 줄고 새 게임에서3개로 복원됩니다.
- 점프 초기 속도를192에서128로 낮췄습니다. 실제 고정 스텝에서 최고 높이는 약37px에서16px로 낮아졌으며8px 압정을 넘을 수 있습니다.
- 낮은 점프에 맞춰 틈 직전의 입력 시점을 조정하고20개 맵의 실제 입력 해법을 다시 검증했습니다.
- 실제 걷기와 사다리 이동에 짧은 효과음, 실제 점프에 상승음, 스테이지 클리어에6음짜리 짧은 멜로디를 추가했습니다.
- 벽에 막혀 움직이지 않을 때는 발소리가 나지 않고, 공중에서 점프를 반복 입력해도 점프음이 중복 발생하지 않습니다.
- 음소거·일시정지·재시작·종료 시 예약된 소리를 중단합니다.
