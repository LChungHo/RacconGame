# 너구리 게임 20스테이지 수정 결과

작성일: 2026-10-30

## 반영한 요청

- 회색 몸통, 둥근 귀, 검은 눈 마스크와 큰 줄무늬 꼬리가 보이는 너구리 도트로 교체했습니다.
- 스테이지는 총20개이며 당근·앵두·버섯·감·옥수수·파인애플·수박·가지·멜론·밤·바나나·딸기·오렌지·무·사과·포도·땅콩·복숭아·완두콩·맥주 순서입니다.
- 먹거리 종류와 관계없이 해당 판에서 먹은 순서에 따라 10,20,30,50,100,200,300,500,1000,2000,3000점을 지급합니다.
- 각 판의 물음표 주머니4개는 위치와 결과가 고정됩니다. 점수 주머니는 보통2개, 3/9단계는1개, 4/12/13단계는3개입니다.
- 뱀 주머니는 즉사 대신 느리게 움직이는 뱀을 생성합니다. 중복 접촉으로 뱀이 반복 생성되지 않습니다.
- 같은 층의 적은 점프로 넘을 수 없으며 사다리로 회피합니다. 적 속도와 틈·장애물·사다리 배치는 단계마다 달라집니다.
- 타이머1에서 목숨을 한 번 차감하고 자동 낙하합니다. 마지막 목숨도 낙하를 거친 뒤 게임 오버가 됩니다.
- 남은 타이머에 따른 클리어 보너스를 유지했습니다.
- 첨부 이미지에 맞춰 검은 1UP/TOP SCORE 점수판, 청록 픽셀 숫자, 파란 시간 막대와20개 먹거리 아이콘을 배치했습니다.
- 숫자 시간 대신 줄어드는 막대만 표시하며 접근성 진행률을 제공합니다. 최고 점수는 브라우저에 저장합니다.

## 구현 선택과 한계

- 12번째 이후 점수는 마지막 값3000점을 유지합니다. 주머니는 먹거리 수집 순서를 올리지 않습니다.
- 주머니 보상 금액은100/200/500/1000의 고정 데이터입니다. 뱀 속도6px/s와 생성 직후0.4초 유예는 구현 선택입니다.
- 원작 맵 좌표와 주머니의 원본 위치를 검증한 것으로 주장하지 않습니다.20개의 서로 다른 고정 맵을 직접 구성했습니다.
- 사다리 구간을 층별로 어긋나게 배치해 버튼을 조금 오래 눌러도 중간 층에서 가로로 빠져나오기 쉽도록 했습니다.
- 내부 타이머는 기존120을 유지하며1에서 사망합니다. 화면은 비율 막대만 표시합니다.
- 모바일은 화면 크기 대응만 포함하고 터치 조작은 추가하지 않았습니다.
- IIS 운영 서버에는 연결하거나 배포하지 않았습니다.
